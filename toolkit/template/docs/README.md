# Numbering the notes

Chapters are numbered 01, 02, … in the order they were discovered, so reading them in order retraces
how the game was understood: `01-disk-location.md`, then the disk format, the boot chain, and so on.
A number is never reused or changed; a later discovery gets the next number and the older chapter
links to it. A note that is not a chapter (a procedure, an index, a backlog) goes unnumbered, one
topic a file, and gets one line in the game's CLAUDE.md.
